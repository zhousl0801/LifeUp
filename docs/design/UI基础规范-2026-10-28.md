# UI 基础规范 · 2026-10-28（2026-11-19 同步）

> 视觉风格、双主题色板与页面级组件规范见 [Midnight Mint 视觉规范](MidnightMint设计规范-2026-11-04.md)。本文件维护文本层级、间距圆角、触控尺寸、BottomSheet 交互、PWA 壳层与异步 loading 的基础工程约束，所有数值均与 `web/src/styles/tokens.css` 保持一致。

## 1. 文本层级

数值来源：`web/src/styles/tokens.css`。正文和说明文字保持可读字号（仅底部悬浮胶囊导航标签为 `11px`）。

| Token | 值 | 用途 |
| --- | --- | --- |
| `--text-caption` | `0.75rem` (12px) | 标签、日期、图表轴、辅助说明 |
| `--text-footnote` | `0.8125rem` (13px) | 次要信息、表单提示 |
| `--text-subhead` | `0.9375rem` (15px) | 列表主文本、设置行 |
| `--text-body` | `1rem` (16px) | 正文和输入 |
| `--text-headline` | `1.0625rem` (17px) | 页面内标题 |
| `--text-title3` | `1.25rem` (20px) | 区块标题 |
| `--text-title2` | `1.375rem` (22px) | 页面标题 |
| `--text-title1` | `1.75rem` (28px) | 一级页面大标题 |
| `--text-large-title` | `2.25rem` (36px) | 首页 / 一级核心大标题 |
| `--text-display` | `2.75rem` (44px) | 资产主金额展示 |

规则：

- 正文不低于 15–16px，说明文字与图表轴不低于 12px。
- 优先使用 400 / 500 / 600 / 700 / 800 常规字重，避免新增非标准合成字重。
- 金额、涨跌幅、日期统一使用 `font-variant-numeric: tabular-nums`。
- 大标题与主金额保留少量负字距，正文不使用负字距。

## 3. 点击尺寸

基础触控目标 `--touch-target: 44px`。返回按钮、脱敏眼睛按钮、趋势范围切换、日历前后月、资产行操作、基金分组胶囊、账单周期与筛选控件均保证至少 `44×44px` 可点区域。

保留的例外：

- BottomSheet 右上角 `.sheet-close` 关闭按钮为 `32×32px` 胶囊（搭配顶部拖拽条下滑关闭及遮罩点击关闭）。
- 分类图标本身是视觉元素，整块分类项的可点击区域大于 44px。
- 底部导航由整格承担点击，不要求图标本身 44px。
- 图表 canvas 的点击由图表坐标系承担，轴标签不作为独立点击目标。

## 4. BottomSheet 与确认弹层

`web/src/components/BottomSheet.vue` 统一交互约束：

- 遮罩淡入 + 面板上滑，使用 `--motion-sheet (320ms)` 与 `--ease-sheet`。
- 面板底色为 `var(--color-bg-page)`，以衬托内部白底 iOS Inset Grouped 表单分组（`.form-field`）。
- 顶部 `36×5px` grabber，按住下滑超过 `96px` 触发关闭；点击遮罩或按 `Escape` 关闭，背景滚动锁定。
- 打开后焦点进入对话框，Tab / Shift+Tab 在对话框内循环，支持多弹层焦点栈，关闭后回到触发元素；不自动聚焦第一个输入框以免弹出软键盘。
- 桌面端 `≥600px` 居中弹框展示；全局 `prefers-reduced-motion` 下关闭动画。
- 所有破坏性确认（删除分组、删除计划、停用工资档案、清空/恢复备份等）统一使用 `ConfirmSheet`，不使用 `window.confirm`。

## 5. 导航

- 底部导航采用 **4+1 悬浮双胶囊**：左侧胶囊为 `账单 / 总览 / 目标 / 我的`（标签字号 `0.6875rem / 11px`，选中态带 `--color-brand-soft` 胶囊底），右侧为独立的 `58×58px` 圆形薄荷绿 `+` 记一笔主操作按钮（带 `aria-label`）。
- `总览 / 账单 / 我的` 区分 outline / filled 图标状态；`目标` 使用统一的靶心图标并凭颜色与胶囊底区分选中态。

## 6. PWA 外观与主题切换

- 主题支持应用内 **跟随系统 / 亮色 / 暗色** 三态切换（存 `localStorage['lifeup.theme']`，切换 `html[data-color-scheme]`），不再只被动依赖 `prefers-color-scheme`。
- `web/index.html` 维护单条 `<meta name="theme-color">`，初始化脚本与 `web/src/utils/theme.ts` 按当前生效主题实时同步为亮色 `#F4F6FA` 或暗色 `#0B0C10`。
- 全局顶部挂载 `.status-bar-scrim` 纯色安全区遮罩，避免 iOS 26 Safari / PWA 滚动时出现状态栏雾化。
- 配置 iOS `apple-mobile-web-app-*` meta、180×180 `apple-touch-icon` 与 192 / 512 PNG / maskable manifest 图标（源文件 `web/public/icons/icon-source.svg`）。

## 7. 图表与缩放

- ECharts 颜色集中由 `web/src/utils/chartTheme.ts` 按当前主题动态读取；切换应用内主题或系统外观时，已挂载图表自动重绘。
- 字号 token 均采用 `rem`，支持根字号缩放；ECharts 轴文字通过 `chartFontSize()` 跟随根字号缩放，不低于 12px。
- 首页趋势图隐藏坐标轴与浮动极值标签，选点读数叠放在图表顶部区域，避免小屏裁切。

## 8. 异步操作与 loading

- 所有发起网络请求、文件读写或耗时计算的功能按钮统一使用 `web/src/components/LoadingButton.vue`：加载中自动禁用、展示旋转指示器并用 `loadingLabel` 说明状态，防止重复提交。
- 取消、关闭、tab、筛选、分页等纯本地交互不需要 loading；图标型异步按钮（如首页同步、计划立即执行）保留旋转状态与 `aria-busy`。
- 页面首次加载使用薄荷微光骨架屏（`.loading-state` / `.loading-block` / `.loading-orbit`）与顶部进度条（`.loading-bar`）。
- 统一反馈顺序：点击 → 进入 loading → 成功提示（`AppMessage`）→ 关闭弹层或刷新数据；失败退出 loading 并保留用户输入。
