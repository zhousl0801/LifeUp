# Midnight Mint 视觉规范

版本：v2.1 · 更新日期：2026-11-19 · 主题标识：`midnight-mint`

方向：**彩色 Hero + 冷瓷白内容（Daylight Prism） / 冷曜石黑 + 顶缘微光（Obsidian Mint）**的金融仪表盘。首页和核心指标页用一整块顶部贴边 Hero 承载主数字、变化和趋势：浅色主题采用“晴空极光紫”（电光靛紫渐变叠加右上角薄荷漫射光），深色主题采用“星夜靛紫”。浅色内容区用冷瓷白底与 5 色分类语义微彩打破单一淡紫；深色内容区采用降饱和冷曜石黑与高对比冷灰白字，配合 `1px` 表面微光描边与顶缘内高光强化层级。

本规范覆盖全局色彩体系、排版形状、核心组件与关键页面规则，单一运行时色彩源为 [ui-color-tokens.css](ui-color-tokens.css)，尺寸与圆角源为 `web/src/styles/tokens.css`。

## 1. 色彩与主题模式

应用在 `<html>` 固定声明 `data-theme="midnight-mint"`，并在「我的 → 主题配色」提供 **跟随系统 / 亮色 / 暗色** 三态切换（写入 `data-color-scheme="light|dark"`），同时动态改写单条 `<meta name="theme-color">`（亮色 `#F4F6FA` / 暗色 `#0B0C10`）。

| 语义 | 浅色（Daylight Prism） | 深色（Obsidian Mint） | 用途 |
| --- | --- | --- | --- |
| Hero | `#3B38B8` → `#5246E5` (+ 薄荷漫射) | `#191838` → `#262154` (+ 薄荷漫射) | 首页、目标页与投资/资产页主视觉头部 |
| Page | `#F4F6FA` | `#0B0C10` | 页面底色（亮色冷瓷白 / 暗色冷曜石黑） |
| Surface | `#FFFFFF` | `#151720` | 卡片、分组块面、列表（配 `1px` 微光边） |
| Subtle | `#EEF1F7` | `#1E212E` | 分段底槽、次级块面、骨架屏基底 |
| Brand | `#4F46E5` | `#818CF8` | 导航选中、主按钮、链接、图表主色 |
| Brand soft | `#EEF2FF` | `#22253E` | 选中底色、轻标签、导航胶囊激活态 |
| Mint | `#7CE7B1` / `#10B981` | `#7CE7B1` / `#34D399` | 正向强调、趋势曲线、右侧独立「＋」记一笔按钮 |
| Text primary | `#111827` | `#F8FAFC` | 标题、正文、金额 |
| Text secondary | `#525B6E` | `#B4BCD0` | 日期、单位、说明（去紫雾高对比冷灰） |
| Text placeholder | `#646E82` | `#8E98B0` | 输入框占位符、弱化辅助字 |
| Text on dark | `#FFFFFF` | `#F8FAFC` | Hero 主文字 |
| Text on dark secondary | `#EEF2FF` | `#CBD5E1` | Hero 标签、辅助说明 |

### 多色分类语义微彩

分类图标与分组徽标按语义自动映射 5 组微彩（`CategoryIcon.vue` 通过 `data-tone` 挂载）：

| Tone | 浅色底 / 前景 | 深色底 / 前景 | 常见归类 |
| --- | --- | --- | --- |
| `amber` | `#FFF3E0` / `#C2610C` | `rgba(245,158,11,0.16)` / `#FBBF24` | 餐饮、日用、居住等高频生活类 |
| `sky` | `#E0F2FE` / `#0277BD` | `rgba(56,189,248,0.16)` / `#38BDF8` | 交通、通讯、出行与服务类 |
| `emerald` | `#E6F8F1` / `#0D8A6A` | `rgba(52,211,153,0.16)` / `#34D399` | 工资、经常收入、健康与结余类 |
| `rose` | `#FCE7F3` / `#C2255C` | `rgba(244,114,182,0.16)` / `#F472B6` | 娱乐、购物、人情与弹性消费 |
| `violet` | `#EEF2FF` / `#4F46E5` | `rgba(129,140,248,0.18)` / `#818CF8` | 默认、投资与其他综合分类 |

财务涨跌遵循国内习惯：**红盈绿亏**（浅色 `#C23838` / `#0D9488`，深色 `#FF7A7A` / `#34D399`，Hero 上使用专用高对比 `--color-finance-gain-on-hero` / `--color-finance-loss-on-hero`）。薄荷绿不表示上涨，只承担品牌、趋势线和主操作强调。

## 2. 字体与数字

- 中文：`PingFang SC`，回退 `HarmonyOS Sans`、`Noto Sans SC`。
- 英文与数字：优先 `SF Pro Display`；数字统一 `font-variant-numeric: tabular-nums`。
- 金额：700～800 字重，主展示字号 `--text-display: 2.75rem (44px)`，搭配 `-0.03em ～ -0.05em` 紧凑字距。
- 正文保持 15～16px，说明文字不小于 12px（仅底部悬浮导航标签为 `11px / 0.6875rem`）。

## 3. 形状、阴影与安全区

| Token | 值 | 说明 |
| --- | --- | --- |
| Hero 圆角 | 底部 `28px`，顶部贴边 | 全宽承接状态栏区域 |
| 卡片圆角 | `24px` (`--radius-card`) | 一级卡片与区块容器 |
| 浮层圆角 | `30px` (`--radius-sheet`) | BottomSheet 顶部圆角 |
| 控件圆角 | `14px` (`--radius-control`) | 按钮、分段底槽与输入分组容器 |
| 标签圆角 | `10px` (`--radius-tag`) | 状态徽标与小标签 |
| 胶囊圆角 | `999px` (`--radius-pill`) | 胶囊按钮、导航栏、切换轨道 |
| 页面边距 / 卡内边距 | `20px` / `20px` | 记一笔全屏键盘页左右保留 `16px` |
| 卡片阴影 | `0 0 0 1px var(--color-surface-border), 0 12px 32px var(--color-shadow)` | 冷灰投影叠加 `1px` 微光表面描边 |
| 浮层阴影 | `0 0 0 1px var(--color-surface-border), 0 18px 40px var(--color-shadow-strong)` | 悬浮导航胶囊与弹层使用 |
| Hero 阴影 | `inset 0 1px 0 rgba(255,255,255,0.14), 0 24px 48px var(--color-shadow-hero)` | 顶缘内高光 + 深邃落地投影 |

- **iOS 26 顶部安全区纯色遮罩（`.status-bar-scrim`）**：顶部固定与 `safe-area-inset-top` 等高的纯色遮罩层，按当前页面是否存在 `.home-hero`、`.entry-screen` 或 `.sheet-backdrop` 以及深浅色动态切换底色，避免 WebKit 滚动时把状态栏区域雾化。

## 4. 核心组件

### Hero 与全局金额脱敏

- **首页 Hero**：顶部左侧为大标题「总览」（不显示品牌名），右侧为更新日期与圆形行情同步按钮；主金额带 `CNY` 标识与 `44×44px` 透明圆形 **金额脱敏按钮（`AmountVisibilityButton`）**（首页与目标页共用全局 `amountsMasked` 状态，默认开启脱敏）。
- **变化与趋势**：变化胶囊展示方向、金额与百分比，点击打开变化构成 BottomSheet（支持按日分项展开）；右侧配套「当日 / 本月」切换胶囊。下方内嵌无坐标轴、无网格线的薄荷绿趋势曲线与渐变面积，底部为深色胶囊范围轨道（`7日 / 1月 / 3月 / 全部`，选中为白底深字胶囊）。

### 卡片与业务视图

- **首页本月收支卡**：位于 Hero 下方首位；上方双列展示本月收入与本月支出（带绿/紫语义色点），中间为 `16px` 高双色比例条（单边达 4 倍以上时弱势段最小保留 `6px` 视觉锚点），底部展示本月结余行。首页不再放置自动记账卡片。
- **首页资产分布（1+2+2 双列流光卡）**：覆盖 **现金、基金、股票、公积金、贵金属** 五类资产。首页采用双列网格（`repeat(2, 1fr)`），第一张「现金」卡片跨两列通栏，其余四类双列排布。每张卡内置按占比 `--share` 定位并带轻呼吸动效的 SVG 流光波浪（`.card-glow`）；浅色主题使用白卡 + 冷灰阴影分层，分类色仅用于图标、占比、链接与右侧流光；深色主题将卡底抬高至 `#1C1F2E → #161824`，加 `rgba(255,255,255,0.09)` 描边、高浓度文字底层遮罩与外发光。资产总览页（`/assets`）保留分段条与列表维护视图。
- **账单预算环与三视图**：账单页顶栏支持周期切换与分类管理入口，首屏以白卡承载本月支出与环形月度预算进度条（点击可编辑当月预算），下方为 `收支日历（默认）/ 账单列表 / 收支图表` 三视图切换。
- **目标页玻璃轨道（`GlassTrack`）**：目标页顶部为 `资本积累 / 自动计划` 分段，Hero 展示总资产进度、脱敏眼睛、月均积累与组合年化，内嵌半透明玻璃凹槽进度轨道、历史自动里程碑星标、当前月份光标与终点菱形；未设目标时展示带薄荷绿脉冲点的紫色引导卡。

### 底部导航（4+1 悬浮双胶囊）

- 采用底边距安全区悬浮的 **4+1 双胶囊布局**（`grid-template-columns: minmax(0, 1fr) 58px; gap: 8px`），取消旧版通栏底栏。
- **左侧主胶囊**：依次为 **账单（`/ledger`）/ 总览（`/`）/ 目标（`/capital`, `/plans`）/ 我的（`/mine`, `/salary`）**。选中项使用 `--color-brand-soft` 胶囊底与品牌色图标文字，标签字号 `11px (0.6875rem)`。
- **右侧独立主操作**：`58×58px` 圆形薄荷绿渐变 `+` 按钮，直达 `/entry` 记一笔；它不属于常规 tab。

### iOS Inset Grouped 表单与 BottomSheet

- **表单分组（`.form-stack` / `.form-field`）**：统一为 iOS 设置风格的联排分组，采用 `16px` 圆角白底块（深色为 `--color-bg-surface`）、组内 `1px` 细分隔线、左侧字段标签 + 右侧透明无边框右对齐输入，聚焦态触发 `focus-within` 4% 品牌淡紫微高亮；只读或来源托管字段明确标注标签（如「工资档案」）。
- **BottomSheet**：面板底色使用 `var(--color-bg-page)`（与内部白底 `.form-field` 形成自然分组对比），顶部 `30px` 圆角，配 `36×5px` 顶部拖拽条（下滑超过 `96px` 关闭）；右上关闭按钮为 `32×32px` 胶囊；支持多弹层焦点栈管理，桌面端 `≥600px` 居中弹框展示。
- **加载态体系**：首屏数据加载采用薄荷微光骨架块（`.loading-block`）、轨道加载指示器（`.loading-orbit`）与顶部细进度条（`.loading-bar`）；写操作按钮统一使用 `LoadingButton` 防止重复提交。

## 5. 页面规则

- 只有承载单一核心指标的页面（总览、投资、股票、贵金属、现金、公积金、目标）使用彩色/深色 Hero；账单明细、分类设置、计划管理、我的页与表单弹层保持浅色/暗色中性内容区。
- Hero 内部不放长列表和复杂表单，复杂操作统一收进 BottomSheet。
- 强调色保持克制：靛紫用于交互和品牌识别，薄荷绿用于趋势线、关键正向强调与「＋记一笔」，5 色微彩仅作用于分类图标与数据可视化。
- 金额、百分比与日期全局启用 `tabular-nums`，避免刷新或切换脱敏态时版面跳动。
