# Midnight Mint 视觉规范

版本：v1.0 · 日期：2026-11-04 · 主题标识：`midnight-mint`

方向：**深色 Hero + 浅色内容**的金融仪表盘。首页用一整块深紫黑区域承载总资产、变化和趋势，下面回到浅灰背景与白色大圆角卡片。品牌紫负责导航、选中和链接，薄荷绿负责正向强调和主操作，青色与橙色只用于图表分类。

本规范先覆盖全局基础与首页；其余页面沿用原有信息架构，逐步替换为同一套 token 和组件语言。

| Surface | `#FFFFFF` | `#1A1730` | 卡片、弹层、列表 |
| Brand | `#5B5BD7` | `#8B86FF` | 导航、选中、链接、图表主色 |
| Brand soft | `#ECE9FE` | `#29244A` | 选中背景、轻标签 |
| Mint | `#7CE7B1` | `#7CE7B1` | 正向强调、图表曲线、新增按钮 |

| Orange | `#EF9849` | `#FFD166` | 图表分类 |

财务涨跌继续采用国内习惯：**红盈绿亏**。薄荷绿不表示上涨，只承担品牌和图表强调，避免与亏损语义混淆。

## 2. 字体与数字

- 中文：`PingFang SC`，回退 `HarmonyOS Sans`、`Noto Sans SC`。
- 英文与数字：优先 `SF Pro Display`；后续可引入 Manrope 作为数字展示字体。
- 金额：700～800 字重，`letter-spacing: -0.03em ～ -0.05em`，`font-variant-numeric: tabular-nums`。
- 标签：12～14px，字重 500～600，使用次级文字色。
- 正文保持 15～16px，说明文字不小于 12px。

| 卡片圆角 | 24px |

卡片不加边框。浅色区用白面、留白和轻阴影分层；深色区用半透明白和亮度差分层。

## 4. 组件

### Hero

- 顶部：品牌名、页面标题、日期、圆形同步按钮。
- 金额：标签 + 超大金额，小数位使用次级色和更小字号。
- 变化：胶囊按钮，内含方向、金额、百分比和信息入口；点击打开变化构成弹层。
- 趋势：无坐标轴、无网格线，只有薄荷绿曲线和渐变面积；选中点读数叠放在图表顶部。
- 范围：深色胶囊轨道，选中项为白色胶囊、深色文字。

### 卡片

- 指标卡：两列，标签 + 大数字 + 一行说明。
- 资产分布：白色卡片内放分段条和资产行，分段之间留 4px 空隙。
- 自动记账：白色卡片内放计划行，日期块使用品牌浅底。

### 导航

- 白底、上缘轻阴影，不再使用分割线。
- 未选中为次级文字色，选中为品牌紫。
- 中间“记一笔”改为薄荷绿圆形按钮，深色加号。

### 表单与弹层

- 输入框使用浅灰紫填充，无边框，聚焦时显示品牌紫描边。
- 主按钮使用胶囊形品牌紫；次按钮使用浅灰紫填充。
- BottomSheet 保持 30px 顶部圆角，拖拽条使用边框色。

## 5. 页面规则

- 只有承载单一核心指标的页面使用深色 Hero；列表、表单和明细页保持浅色内容区。
- 深色 Hero 内不放表格、长列表和复杂操作。
- 强调色面积保持克制：紫色用于交互，薄荷绿用于少量正向数据与主操作，青色和橙色只在图表出现。
- 金额、百分比、日期统一使用等宽数字，避免刷新时跳动。
