# Midnight Mint 视觉规范

版本：v2.1 · 日期：2026-11-17 · 主题标识：`midnight-mint`

方向：**彩色 Hero + 浅色内容（Daylight Prism） / 冷曜石黑 + 顶缘微光（Obsidian Mint）**的金融仪表盘。首页用一整块 Hero 承载总资产、变化和趋势：浅色主题是“晴空极光紫”（电光靛渐变叠加右上角薄荷漫射光），深色主题是“星夜靛紫”。浅色内容区采用通透冷瓷白底与多色语义微彩（按分类图标语义自动映射暖橙、晴空蓝、翡翠绿、珊瑚粉、靛紫）；深色内容区采用降饱和冷曜石黑与高明度中性冷灰白字，消除紫雾同化，配合 `1px` 顶缘/表面微光描边强化层级。

本规范覆盖全局基础、色彩体系与各核心业务页面。

| 语义 | 浅色 | 深色 | 用途 |

| Page | `#F4F6FA` | `#0B0C10` | 页面底色（亮色冷瓷白 / 暗色冷曜石黑） |
| Surface | `#FFFFFF` | `#151720` | 卡片、弹层、列表（配合 `1px` 微光边） |
| Subtle | `#EEF1F7` | `#1E212E` | 内嵌输入框、分段底槽、次级块面 |

浅色主题的 Hero 是“白日紫”：品牌紫渐变配白字，阴影带紫，不再是接近黑色的蓝紫；深色主题的 Hero 是“夜色紫”，两者共用同一套白字、胶囊和薄荷绿曲线。

财务涨跌继续采用国内习惯：**红盈绿亏**。薄荷绿不表示上涨，只承担品牌和图表强调，避免与亏损语义混淆。

## 2. 字体与数字

- 中文：`PingFang SC`，回退 `HarmonyOS Sans`、`Noto Sans SC`。
- 英文与数字：优先 `SF Pro Display`；后续可引入 Manrope 作为数字展示字体。
- 金额：700～800 字重，`letter-spacing: -0.03em ～ -0.05em`，`font-variant-numeric: tabular-nums`。
- 标签：12～14px，字重 500～600，使用次级文字色。
- 正文保持 15～16px，说明文字不小于 12px。

## 4. 组件

### Hero

- 顶部：品牌名、页面标题、日期、圆形同步按钮。
- 金额：标签 + 超大金额，小数位使用次级色和更小字号。
- 变化：胶囊按钮，内含方向、金额、百分比和信息入口；点击打开变化构成弹层。
- 趋势：无坐标轴、无网格线，只有薄荷绿曲线和渐变面积；选中点读数叠放在图表顶部。
- 范围：深色胶囊轨道，选中项为白色胶囊、深色文字。“当日 / 本月”切换沿用同一套胶囊轨道。

### 卡片

- 指标卡：两列，标签 + 大数字 + 一行说明。
- 首页资产分布采用扑克牌式叠放。当前卡水平置顶，上下相邻卡反向倾斜，露出带资产名的卡角。上下滑动或点击卡角切换，亮色渐变边缘随占比移动。资产管理页用分段条和列表。
- 资产卡两套配色。深色主题把卡底抬到 `#262142 → #1E1A36`，加 1px 白 8% 描边和内高光，分类色同时用在荧光流光、占比数字和卡片外发光上，靠光而不是靠黑色投影分层；浅色主题换成白卡，分层靠白面和阴影，分类色只出现在图标、占比数字、链接和右侧流光上，不用荧光色当文字（`#2be7a8` 对白底只有 1.6:1）。
- 自动记账：白色卡片内放计划行，日期块使用品牌浅底。

### 导航

- 白底、上缘轻阴影，不再使用分割线。
- 未选中为次级文字色，选中为品牌紫。
- 中间“记一笔”改为薄荷绿圆形按钮，深色加号。

### 表单与弹层

- 输入框使用浅灰紫填充，无边框，聚焦时显示品牌紫描边。
- 主按钮使用胶囊形品牌紫；次按钮使用浅灰紫填充。
- BottomSheet 保持 30px 顶部圆角，拖拽条使用边框色。

## 5. 页面规则

- 只有承载单一核心指标的页面使用深色 Hero；列表、表单和明细页保持浅色内容区。
- 深色 Hero 内不放表格、长列表和复杂操作。
- 强调色面积保持克制：紫色用于交互，薄荷绿用于少量正向数据与主操作，青色和橙色只在图表出现。
- 金额、百分比、日期统一使用等宽数字，避免刷新时跳动。
