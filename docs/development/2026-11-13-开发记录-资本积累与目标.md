## 4. 已知边界

- 星标是自动里程碑，不是手动记录；手动记录、多目标、通胀调整和保守 / 基准 / 乐观情景留待后续版本。
- 轨道年份刻度按预测年末资本定位，不是等距时间轴。
- 光标标签是当前业务月份，不是最近一条账本记录的日期。
- 首页不增加资本积累摘要入口，按用户要求只保留底部「目标」入口。

## 6. 2026-11-13 补充：目标引导与表单快捷填充

- 未设目标时，「设定目标」从普通按钮改为带目标图标、引导文案和薄荷绿脉冲点的整行按钮；脉冲在减少动态效果时停用。
- 目标金额输入单位改为万元，最多 4 位小数（1 元 = 0.0001 万），提交时转换为元；示例 100 表示 100 万。
- 月收入可从启用中的工资 / 定期收入计划一键填入；月支出从当前月预算填入，没有预算时回退上一个完整月实际支出；公积金月缴存从启用中的公积金缴存计划填入。
- 投资年化可手动填写，也可应用「纳指100 20年 ≈13%」「标普500 20年 ≈10%」两个历史参考值；这是固定参考常量，不接实时指数行情，也不构成投资建议。
- 表单按同类分组：目标整行；收入 / 支出一行；公积金缴存 / 公积金年化一行；收入增长 / 支出增长一行；投资年化整行并带快捷项。
- 新增前端测试覆盖万元换算、三个快捷填充、两个投资预设、字段分组和未设目标引导；前端全量 243 项通过，类型检查和构建通过（PWA 预缓存 59 项）。后端未改动，仍为 430 项（412 通过 + 18 跳过）。
