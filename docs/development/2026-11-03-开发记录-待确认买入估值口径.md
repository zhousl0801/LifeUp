# 2026-11-03 待确认买入的估值口径

## 问题

11 月 3 日打开「投资收益走势 · 本月」，页面显示「净值披露 0 天」，但同一屏的「区间盈亏」是 **-19.23**，图表空白、日历三天全是「—」。没有净值披露却有钱，两个数字互相矛盾。

逐只核对 `/api/ledger/funds/returns`，有金额的正好是三只 10-29 买入、11-02 确认的基金：

| 基金 | 区间盈亏 |
| --- | --- |
| 华夏移动互联 002891 | -8.05 |
| 国富全球科技 006373 | -4.85 |
| 建信新兴市场 018147 | -6.33 |
| 其余 5 只 | 0.00 |
| 合计 | -19.23 |

## 成因

买入当天下单后份额未确认，重放把「待确认买入」按**承诺金额**计入 `PendingAmount`，估值就等于这笔钱原封不动挂着。确认发生时（`FundBuyConfirm`）才换成「份额 × 最新净值」。

三笔 10-29 买入的实际数字：

1. 10-29 扣款 100 元，T 日净值 2.4240，确认后是 41.2541 份；
2. 但确认发生在 11-02，估值用的是**当时的最新净值**，也就是 10-30 的 2.2290；
3. `41.2541 × 2.2290 = 91.96`，比原来挂的 100 少 8.04。

于是「10-29 到 10-30 这一天的下跌」被一次性砸在 11-02，落进了 11 月的区间盈亏——可 10-30 既不在本月区间内，那天也没有任何净值披露。

只要还有定投，每一笔 T+2 确认都会复现同类差价：金额挂账 → 最新净值重估 → 差价落在确认日。

## 修改

**待确认买入从 T 日起就按 T 日净值折算成份额计值**，不再按承诺金额挂账。

- `BusinessFact` 增加 `FundTradeDate`，重放时用「T 日净值」把待确认金额折成隐含份额。
- `LedgerReplayCalculator` 在每个持仓上记录未确认的买入（`PendingBuys`，键为待确认记录 Id），重放结束时按 `金额 ÷ T 日净值 × 当日净值` 折算，结果放在新字段 `HoldingReplay.PendingMark`。
- `HoldingReplay.PendingValue` 统一对外：有折算值就用折算值，T 日净值还没披露时退回承诺金额（这段时间不参与盈亏计算）。
- 估值出口统一换成 `PendingValue`：`KnownTotalAssets`、`LedgerService` 首页资产卡、`MonthChangeService`、`TrendService`、`FundService`（总市值与各基金合计）、`FundReturnService`（区间盈亏、区间收益、每日收益）。
- `PendingAmount` 仍然保留，用于「待确认 2,240.00」这类**承诺金额**展示，不参与估值。

## 效果

真实账本（Supabase）重启后端后：

| 指标 | 修改前 | 修改后 |
| --- | --- | --- |
| 区间盈亏（11-01~11-03） | -19.23 | -0.01（纯四舍五入） |
| 净值披露天数 | 0 | 0 |
| 各基金区间盈亏 | -8.05 / -4.85 / -6.33 | 全部 0.00，残留 ±0.01 |
| 基金总市值 | 279,985.82 | 279,985.82（不变） |
| 待确认金额 | 2,240.00 | 2,240.00（仍是承诺金额） |

## 测试

新增 `api/tests/LifeUp.Tests/Funds/FundPendingValuationTests.cs` 五例：

1. `PendingBuy_IsMarkedAtTradeDateNetValue_BeforeConfirmation`：T 日净值 2.0、当日 1.8 时，600 元待确认折算成 540，总额 2,340 而非 2,400。
2. `ConfirmingPendingBuy_DoesNotChangeTotalValue`：确认前后总市值不变，待确认清零。
3. `MonthReturn_IgnoresRevaluationCausedByConfirmation`：区间内没有净值披露、没有资金变动时，区间盈亏必须是 0，且所有点都没有当日收益。
4. `PendingBuy_WithoutTradeDateNetValue_FallsBackToAmount`：T 日净值未披露时仍按承诺金额计值，不猜净值。
5. `DailyProfit_OnDisclosureDate_IncludesPendingRevaluation`：净值披露日当日收益同时包含已确认份额和待确认部分的变动（-200 与 -60 合计 -260），保证折线与区间盈亏同源。
