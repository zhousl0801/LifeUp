## 当前覆盖的产品形态

- **双主题与三态切换**：支持「跟随系统 / 亮色（Daylight Prism）/ 暗色（Obsidian Mint）」，可在舞台顶栏或「我的 → 主题配色」中实时切换。
- **4+1 悬浮双胶囊导航**：左侧胶囊依次为「账单 / 总览 / 目标 / 我的」，右侧为独立圆形薄荷绿「＋」记一笔主操作按钮。
- **首页总览**：顶部晴空极光紫 / 星夜靛紫 Hero（总资产、`CNY`、全局金额脱敏眼睛、当日/本月变化切换与明细拆解弹层、无坐标轴薄荷绿趋势图）→ 本月收支双色比例拔河卡 → **1+2+2 双列流光资产分布卡**（现金通栏 + 基金 / 股票 / 公积金 / 贵金属双列）。
- **账单、分类与记一笔**：本月支出与环形月度预算（支持点击修改预算）、默认收支日历 / 账单列表 / 收支图表（一/二级分类切换）三视图、独立两级分类管理页、四则运算数字键盘与「保存后再记 / 完成」（实时联动现金与总资产）。
- **目标（资本积累 + 自动计划）**：顶部 `GoalTabs` 切换；资本积累页含脱敏眼睛、玻璃轨道与自动里程碑、年度推演表（含年终奖）、本月实际与 iOS Inset Grouped 假设抽屉；自动计划页含三分组折叠卡片（带「工资档案」托管标签）与 2026 年 11 月三地交易日历。
- **五类资产详情与我的页**：现金（含余额核对联动）、基金（分组胶囊、含待确认卡片口径与 A/C 份额展开）、股票（A 股与场内 ETF 三位小数精度与排序）、公积金（提取联动现金）、贵金属（Au99.99 现货来源、总收益与报价刷新），以及我的页（个人头像昵称、默认脱敏工资档案、主题配色与备份 V5 说明）。

## 本地预览

在仓库根目录执行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

随后在浏览器打开 <http://127.0.0.1:4173/prototype/>。

## 演示边界

- 初始演示总资产 ¥337,900.00（现金 23,400 + 基金 168,000 + 股票 51,500 + 公积金 68,000 + 贵金属 27,000），所有数值均为虚构示例，刷新页面后重置。
- 原型为纯静态前端交互演示，不连接后端数据库、真实行情或后台定时任务。
