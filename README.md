# LifeUp

个人资产观察与日常记账应用。用一个统一的现金池承接日常收支，并将分散在不同渠道的基金、A 股与场内 ETF / LOF、公积金和平台积存金汇总到同一处，持续跟踪家底变化与长期资本积累目标。

---

## 产品定位与解决的问题

在日常财务管理中，生活开支、工资公积金与多平台投资往往彼此割裂：记账软件只管流水，券商和基金 App 各看各的持仓，月底很难算清“资产到底增加了多少、增加来自哪里”。

LifeUp 围绕个人实际记账与看账习惯，重点解决五件事：

- **看清家底**：打开首页即可看到现金、基金、股票、公积金、积存金五类资产的合计、结构分布及长期趋势。
- **顺手记账**：不拆零散的银行卡、微信或支付宝账户，所有日常消费与收入统一进出一个现金池，记一笔即同步现金余额。
- **归集投资**：把多平台的基金（含 QDII）与场内股票 / ETF 汇总查看，支持按投资方向分组，跨渠道归集同一基金的持仓、成本与收益。
- **减少重复维护**：通过工资档案与自动记账计划，到期自动记录工资入账、公积金缴存 / 提取与基金定投扣款，资金与持仓自动联动。
- **解释资产变化**：把当日和本月的资产变化拆解为生活结余、公积金缴存、投资盈亏与核对差额，既能随时和实际余额对账，也能追溯每一笔变动来源。

## 产品形态与核心功能

应用采用手机端 Web App / PWA 形态（以移动端竖屏体验为主，桌面浏览器沿用手机画幅），支持 **跟随系统 / 亮色 / 暗色** 双主题切换，通过底部 4+1 悬浮双胶囊导航组织核心功能：左侧胶囊为 **账单 / 总览 / 目标 / 我的**，右侧为独立的薄荷绿圆形 **＋记一笔** 主操作按钮。

### 1. 总览：一屏掌握资产全貌与变化构成

- **资产口径自动演进与全局脱敏**：现金始终计入；其余四类资产（基金、股票、公积金、贵金属）在录入持仓或标记“不持有”后，首页自动从“已记录资产”升级为完整“总资产”。内置全局金额脱敏开关（默认开启），保护日常看账隐私。
- **同口径变化拆解**：默认展示“当日变化”并可切换“本月变化”，点击即可展开各资产盈亏、生活结余、公积金缴存与核对差额明细，新增补录单独列出，不扭曲收益表现。
- **本月收支与双列流光资产卡**：以双色比例条直观对比本月收入支出与结余；下方采用 1+2+2 双列流光卡片呈现五类资产的金额、占比、近期变动与详情入口。
- **资产走势与行情同步**：提供 7 日、1 月、3 月及全部范围的按日资产曲线；自动定时更新基金净值、股票行情与参考金价，也支持首页一键手动同步。

### 2. 账单与「＋记一笔」：围绕单一现金池的日常收支

- **极简记一笔**：底部右侧常驻「＋」入口，支持两级用途分类、四则运算数字键盘、「保存后再记 / 完成」以及历史日期补录、修改与撤销，按差额自动联动现金。
- **两级分类独立管理**：在独立分类管理页维护一级分组与二级分类，支持新增、改名、图标配置、启停以及长按拖拽排序与跨组移动；改名同步更新历史流水，停用不影响历史统计。
- **月度预算与三视图账单**：内嵌月度预算进度环，实时提醒剩余预算与日均可花；支持在**收支日历（默认）/ 账单列表 / 收支图表**间切换，并可按一级/二级分类查看排行或筛选明细。

### 3. 各类资产与投资管理：贴合真实交易与对账习惯

从总览页的资产分布卡片可分别进入五类资产详情：

- **现金**：汇总日常收支、资产买卖流转与余额净变动。发现账面与实际存款不一致时，可直接做“余额核对”，差额独立记录为核对调整，不污染日常消费与收入统计。
- **基金（场外 / QDII）**：
  - **组合与分组视角**：支持自定义投资分组（如纳指、标普、红利等）。同名基金自动归集，同类别份额（如 A 类或 C 类）跨购买渠道汇总金额、份额与成本，A/C 类之间保持分列、不混算净值。
  - **完整在途闭环**：还原真实的“买入扣款（待确认）→ 确认份额 → 赎回申请（冻结份额）→ 赎回确认（待到账）→ 赎回到账（转入现金）”流程，在途资金计入基金总资产但不虚增持仓收益率分母。
  - **收益走势与日历**：按净值实际披露日归属收益，区分“区间盈亏”与“持有收益”，提供收益曲线与按日收益日历。
- **A 股与场内 ETF / LOF**：支持多持仓录入、买入、卖出与持仓核对，自动同步最新价与昨收，计算扣除当日资金流入流出后的今日盈亏（非交易日展示最近交易日表现）。
- **公积金**：合并管理个人与单位缴存余额，支持记录起始余额、日常缴存及提取至现金（提取后等额增加现金）。
- **平台积存金**：按克数与成本管理黄金持仓，自动获取上海黄金交易所现货及银行积存金参考报价，支持买入扣现与卖出直接到账。

### 4. 目标：资本积累推演与自动记账计划

目标页整合了长期的“资本积累”与周期执行的“自动计划”：

- **资本积累与目标**：
  - 设定总资产目标（按万元为单位），直观展示当前完成进度、玻璃轨道与自动计算的阶段里程碑。
  - 结合当前资产分桶、每月预计储蓄 / 定投金额及参考年化收益率（支持纳指 / 标普 20 年历史参考年化或自定义假设），按月推演达标时间，并与“本月实际”进展对照。
- **自动记账计划**：
  - 统一管理**基金定投、公积金（缴存 / 提取）、定期收入（工资 / 年终奖）**三组周期计划，到期由后台自动生成账面记录并联动现金与在途持仓。
  - 针对 QDII 与跨境基金定投，内置**中、美、港三地交易日历**，整月日历直观标注因香港或美国休市而顺延的定投日期，并提供待处理期次的补记、重试或跳过操作。

### 5. 我的：工资档案、主题配色与数据主权

- **工资档案**：在「我的 → 个人信息」中集中维护税前 Base、税后月薪、公积金双边缴存与年终奖（默认脱敏展示），自动测算年度到手现金与公积金年积累，保存后一键同步至工资、公积金和年终奖自动计划，并为资本积累推演提供默认现金流假设。
- **个性化主题配色**：支持在「跟随系统 / 亮色（Daylight Prism）/ 暗色（Obsidian Mint）」之间自由切换，页面与图表实时同步。
- **数据导出与完整备份**：支持导出包含收支、交易、核对与计划期次的明细 CSV 用于外部对账；支持下载完整账本 JSON 备份（版本 V5，兼容 V1–V5），并在恢复前做完整性校验与历史重放核对，确保个人财务数据完全自主可控。

## 产品边界说明

为保持轻量与专注，LifeUp 明确不涉及以下范围：

- **不触碰真实资金交易**：不连接银行卡自动扣款，不向基金平台或券商直接下单，所有定投、买入与赎回均为账面记录与资产跟踪。
- **不拆分多生活账户**：不分别维护微信、支付宝或多张储蓄卡余额，也不包含信用卡账单、房贷车贷、房产估值及家庭多人共享账本。
- **个人自用定位**：当前版本面向个人单账本使用（云端与本地均可运行），不内置多租户社交或投资推荐。截图智能识别导入仍在规划中。
